# RSVP Nano Tweaks v0.0.9-tweaks.4

This release includes all fixes from `v0.0.9-tweaks.3` and fixes the native
test build configuration for the Unicode filename sanitizer.

## CI fix

- Link `src/storage/fs/StoragePaths.cpp` into the native test environment so
  `test_filename_sanitizer_preserves_polish_utf8` can run.
- The production Rev2 firmware already linked this source; this correction is
  limited to the desktop test target.

## Waveshare 3.49 Rev2 OTA

Use `rsvp-nano-esp32-s3-touch-lcd-3.49-rev2-ota.bin` and set the Companion
release tag to `v0.0.9-tweaks.4`.
