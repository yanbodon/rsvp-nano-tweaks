# RSVP Nano Tweaks v0.0.9-tweaks.2

This patch release keeps all changes from `v0.0.9-tweaks.1` and fixes the
screen-rotation label for the fonts bundled with RSVP Nano.

## Fix

- Replace the degree symbol in the 180-degree rotation label with localized
  words. The bundled PixelAE font does not contain U+00B0, which caused the
  generated-localization check to fail and could render a missing glyph.

## Waveshare 3.49 Rev2 OTA

Use this exact release asset:

`rsvp-nano-esp32-s3-touch-lcd-3.49-rev2-ota.bin`

In Companion, set the release source to `yanbodon/rsvp-nano-tweaks` and the
release tag to `v0.0.9-tweaks.2`. OTA preserves device settings and books on
the SD card.
