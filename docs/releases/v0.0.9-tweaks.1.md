# RSVP Nano Tweaks v0.0.9-tweaks.1

This custom release is based on upstream RSVP Nano v0.0.9 and targets the Waveshare ESP32-S3
Touch LCD 3.49 Rev2.

## Changes

- Preserve valid UTF-8 letters and combining marks in uploaded filenames. Names such as
  `Męczennik` and `Zażółć gęślą jaźń` no longer degrade into hyphens.
- Distinguish EPUB font obfuscation from content encryption. The standard IDPF and Adobe font
  obfuscation algorithms are accepted; DRM and other encrypted content remain unsupported.
- Add a persistent **Rotate screen 180°** setting to the device and Companion display settings.
  Display output and touch coordinates rotate together, and the selection survives a restart.
- Add regression coverage for Polish text, Unicode filenames, EPUB encryption classification,
  the settings wire format, and the rotation setting helper.

## OTA installation

Publish the Rev2 OTA image with the exact asset name:

`rsvp-nano-esp32-s3-touch-lcd-3.49-rev2-ota.bin`

On the Nano or in Companion, set the release source to the fork repository and use the exact
release tag `v0.0.9-tweaks.1`. The tag must point to the commit used to build the firmware so the
installed version matches the version resolved by the updater.

OTA installation updates the application partition and preserves settings, Wi-Fi credentials,
reading progress, and microSD content. Do not use this Rev2 image on Rev1 hardware.

## After updating

Previously uploaded books with already-mangled filenames are not renamed automatically. Remove
and upload those files again after updating. Original EPUB files containing only font obfuscation
can also be copied to the microSD card for on-device conversion.
