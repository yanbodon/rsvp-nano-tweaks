# RSVP Nano Tweaks v0.0.9-tweaks.5

This release fixes custom GitHub repositories used as an OTA source.

## OTA repository fix

- Correctly parse `owner/repository` values saved by Companion.
- Avoid corrupting the repository name when the input and output use the same
  settings string.
- Add a regression test for `yanbodon/rsvp-nano-tweaks`.

## Waveshare 3.49 Rev2 OTA

Use `rsvp-nano-esp32-s3-touch-lcd-3.49-rev2-ota.bin` and set the Companion
release tag to `v0.0.9-tweaks.5`.
