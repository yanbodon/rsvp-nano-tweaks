# RSVP Nano v0.1.1-tweaks.2

Incremental release based on `v0.1.1-tweaks.1` and upstream RSVP Nano `v0.1.1`.

## OTA source improvements

- Add explicit **My tweaks**, **Official**, and **Custom** release-source choices in firmware and Companion settings.
- Resolve **My tweaks** to `yanbodon/rsvp-nano-tweaks` and **Official** to `ionutdecebal/rsvpnano`.
- Treat a blank release tag as `latest`, so routine OTA checks do not require manually entering each tag.
- Keep firmware and Companion effective-source handling aligned, including the fallback repository used with a bare custom owner.
- Migrate the legacy tweaks bootstrap settings without overwriting explicit custom repositories or pinned tags.

## Companion Pages

- Build the Companion site for the fork at `/rsvp-nano-tweaks/`.
- Allow Pages builds only for the official upstream and `yanbodon/rsvp-nano-tweaks`.
- Run the complete Pages build and smoke test in pull requests while keeping deployment disabled until changes reach the publishing branch.

## Preserved tweaks

This release retains the `v0.1.1-tweaks.1` functionality, including Polish/Unicode EPUB filename handling, EPUB font-obfuscation support, safe custom OTA parsing, 180-degree display rotation for supported regular and watch layouts, regenerated localization, and labels that avoid the unsupported degree glyph.

## Validation

The functional candidate at commit `58311799f333d749bfcb309472116787bf272a83` received final QA **ACCEPT**. GitHub Actions passed for:

- native firmware tests and generated localization,
- Companion web checks and production bundle,
- Android checks and application build,
- iOS checks and application build,
- fork Pages build and `/rsvp-nano-tweaks/` smoke test.

The pull-request Pages deployment was intentionally skipped. Production Pages deployment occurs only after the publishing branch is updated.

## Upgrade and rollback

A blank tag follows the latest compatible release from the selected source. Set an explicit tag only when a pinned firmware version is required. The previous stable release remains available as `v0.1.1-tweaks.1` for rollback.
