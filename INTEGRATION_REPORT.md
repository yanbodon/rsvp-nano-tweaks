## Resolved porting conflicts

1. The old fork targeted an obsolete interface-settings screen layout. The port applies rotation controls to upstream's separate `regular/` and `watch/` screen implementations, preserving the feature instead of restoring obsolete code.
2. Upstream's localization generation format was retained. Source strings were changed first, then `Localization.generated.cpp` and all locale ZIP packs were regenerated deterministically.
3. OTA parsing was factored into a dedicated parser with independent temporary output strings, avoiding the input/output aliasing corruption risk in the old-style caller flow.
4. The native test source filter initially omitted `src/storage/fs/StoragePaths.cpp`; `platformio.ini` now includes it for `native_test`, allowing filename-sanitizer coverage to link.
